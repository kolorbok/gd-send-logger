# v2.0.19

- Difficulty picker: enlarged native difficulty icons/captions.
- Demon tiles now fully hide the baked generic `DEMON` caption and show only `EASY DEMON` / `MEDIUM DEMON` / `HARD DEMON` / `INSANE DEMON` / `EXTREME DEMON`.
- Difficulty star counts use a larger star icon with corrected vertical alignment.
- Feedback editor keeps the 1500-character limit.
- Reopening feedback initializes the native insertion cursor at the end of the saved text.
- The custom multiline caret now follows the real CCTextInputNode cursor, including Left/Right navigation, and the visible line window follows the caret when it moves through wrapped text.
