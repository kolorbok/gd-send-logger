# GD Requests

GD Requests connects Geometry Dash with your Discord server's request system.

## Features

- View server level requests directly in Geometry Dash.
- Open detailed request information, including descriptions and review information.
- Submit request results from the in-game rating flow.
- Send and reject requests through the GD Requests workflow.
- Log Geometry Dash sends through GD Send Logger.
- Use Discord-provided connection and logger keys to connect the game to your server.

GD Requests is designed to work together with the GD Requests Discord bot and its server-side integration.
